# Asha H - Professional Resume & Portfolio Builder

A modern resume and portfolio builder for showcasing software engineering experience, AI/ML projects, Android applications, certifications, and professional accomplishments.

## Live Demo

https://resume-builder-staging.vercel.app/

## Features

- Professional resume editing and preview
- ATS-friendly resume checking
- Portfolio sections for about, experience, projects, skills, and contact details
- Theme customization for personal branding
- Responsive design for desktop and mobile viewing

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm run dev`
3. Open the app in your browser at:
   `http://localhost:3000`

## Deployment

This project is deployed on Vercel:
- Live site: https://resume-builder-staging.vercel.app/
